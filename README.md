# Word-level языковая модель на LSTM и GRU

Языковая модель, которая предсказывает следующее слово. Обучена на отзывах **IMDb**. Сравниваю LSTM и GRU по перплексии на тесте.

## Данные

- Отзывы `stanfordnlp/imdb` (train + unsupervised), разбитые на предложения через `sent_tokenize`
- Оставил предложения короче 32 слов, получилось **811 тыс.** предложений
- Словарь из 40 тыс. самых частых слов + служебные токены `<unk>`, `<bos>`, `<eos>`, `<pad>`
- Разбиение 80 / 10 / 10 на train / val / test

## Что сделано

- `Dataset`, который оборачивает предложение в `<bos>` … `<eos>`, и `collate_fn` с паддингом. Таргет: вход, сдвинутый на один токен
- Train loop и `evaluate` с нуля: `CrossEntropyLoss` с `ignore_index` для паддинга, перплексия $\text{PPL} = e^{\text{loss}}$
- Модель: `Embedding(256) → RNN-блок(256) → Linear(vocab)`, Adam, 5 эпох

## Результаты (перплексия на тесте, чем меньше, тем лучше)

| № | Модель | Perplexity |
|---|---|---|
| 1 | LSTM, 1 слой | **125.0** |
| 2 | GRU, 1 слой | 132.5 |
| 3 | GRU, 2 слоя | 130.0 |

**Выводы:**
- Однослойная LSTM лучше GRU на 7 пунктов. Второй слой GRU дал всего −2 пункта
- Все модели **переобучаются**: train loss падает все 5 эпох, а валидационная перплексия перестаёт снижаться после 3–4 эпохи

**Что попробовать дальше:** dropout, gradient clipping, early stopping, больший размер скрытого состояния.
